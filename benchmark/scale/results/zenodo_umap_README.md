# A UMAP of every cell of Tahoe-100M

Two-dimensional UMAP coordinates for all 95,624,334 cells of Tahoe-100M, the
single-cell perturbation atlas by Tahoe Therapeutics and the Arc Institute
(Zhang et al., Cell 2026, doi:10.1016/j.cell.2026.08.035). The coordinates
were made for the AnnZarro manuscript (Otto, Baasri and Setty, preprint, no
DOI yet: it is added to this record when the preprint is posted), which draws every cell of Tahoe-100M in a web browser. Tahoe-100M itself
ships without a UMAP.

## Files

| file | rows | columns | size | sha256 |
| --- | ---: | --- | ---: | --- |
| `tahoe100m_umap.parquet` | 95,624,334 | `cell_index` (int64), `BARCODE_SUB_LIB_ID` (string), `umap_1`, `umap_2` (float32), `is_reference` (bool) | 1,205.4 MB (1,205,375,373 bytes) | `59e02936b9e5dc3678b228e39a90db2916f96e709ec97e4310e01209f64c7158` |
| `tahoe100m_umap_reference.parquet` | 999,073 | `cell_index` (int64), `BARCODE_SUB_LIB_ID`, `plate`, `cell_line_id` (string) | 7.1 MB (7,081,992 bytes) | `4b35b30fdba4202267bf848787db2e6b160d0a566e02ba01229056b721ae018d` |

`SHA256SUMS` lists the same checksums in `sha256sum -c` format. Both files are
Apache Parquet with zstd compression.

- **`cell_index`** is the cell's row in Tahoe-100M's order: the Hugging Face
  release `tahoebio/Tahoe-100M` (dataset card last modified 2025-07-23),
  3,388 parquet shards read in file order, then rows within each shard in
  order.
- **`BARCODE_SUB_LIB_ID`** is the release's cell identifier. All 95,624,334
  values are distinct (checked when the file was written).
- **`is_reference`** marks the cells the UMAP was fitted on.
- The raw little-endian float32 bytes of `[umap_1, umap_2]` in `cell_index`
  order have sha256 `575e8bb1efac3a69d556d129f3d44b53946501554b0122061a60766e3fda458a`. That is the `obsm/X_umap` used for the
  figures.

## How to join with Tahoe-100M

Join on `BARCODE_SUB_LIB_ID`, or on the position: reading the shards in file
order gives row `cell_index`. In Python:

```python
import pandas as pd
umap = pd.read_parquet("tahoe100m_umap.parquet", columns=["BARCODE_SUB_LIB_ID", "umap_1", "umap_2"])
cells = pd.read_parquet("train-00000-of-03388.parquet", columns=["BARCODE_SUB_LIB_ID"])  # any shard
cells = cells.merge(umap, on="BARCODE_SUB_LIB_ID", how="left")
```

In an AnnData object built from the shards in order, the coordinates go to
`adata.obsm["X_umap"] = umap[["umap_1", "umap_2"]].to_numpy()`. Check
`adata.obs_names` against `BARCODE_SUB_LIB_ID` first.

## Method

The script is `benchmark/scale/umap_tahoe.py` in the AnnZarro paper
repository (github.com/settylab/annzarro-reproducibility, commit 09496f7, the code as run on the Fred Hutch HPC on 2026-10-02/03, with `build_tahoe.py` for the PCA). This
deposit was assembled by `benchmark/scale/zenodo_umap.py` (commit 0cfa477).

1. **Expression space.** Counts are normalised to 10,000 per cell, then
   log1p. The 2,000 genes of highest variance are kept and centred, and 50
   principal components are computed by randomised SVD (seed 0). The PCA is fitted on the reference cells of step 2 (`build_tahoe.py refit`). PC1 and PC2 explain 2.35% and 1.64% of the variance of the 2,000 genes, and the 50 PCs together 17.0%.
   Every cell is then projected exactly onto the 50 components (the map is
   linear).
2. **Reference sample.** Up to 1,430 cells are drawn from every stratum of
   plate x `cell_line_id` (all cells of a smaller stratum; numpy
   `default_rng(0)`). That gives 999,073 reference cells from 700 strata (14 plates x 50 cell lines; 10 strata had fewer than 1,430 cells, all of them CVCL_1571).
   - The ids in `tahoe100m_umap_reference.parquet` were regenerated by
     `zenodo_umap.py`, with the same rule and seed, from the cells' plate and
     `cell_line_id`.
   - They match the UMAP run in the total (999,073) and in the count of each
     of the 700 strata (`benchmark/scale/results/hpc/umap/ref_strata.csv`).
   - The run's own index file was not archived, so identity cell by cell
     follows from the deterministic rule. It was not compared directly.
3. **Fit.** umap-learn 0.5.12 (pynndescent 0.6.0, numba 0.68.0, numpy 2.4.6, Python 3.11.6) on the reference cells' 50 PCs:
   `n_neighbors=15`, `min_dist=0.3`, `metric="euclidean"`, `random_state=0`.
4. **Placement.** For every other cell, its 15 nearest reference cells in PC
   space are found with faiss faiss-cpu 1.15.1 IVF-Flat (`nlist=4096`,
   `nprobe=32`). The cell's coordinates are the mean of their UMAP coordinates,
   weighted by 1/(L2 distance + 0.001). Reference cells keep their fitted coordinates.
   - Recall of the 15 neighbours against exact search, on 100,000 random
     non-reference cells: 0.997.
5. **Validation** (on samples of the layout):
   - 15-nearest-neighbour cell-line purity: 0.948 (0.950 in PC space;
     0.027 at random);
   - silhouette by cell line: 0.597 (0.162 in PC space);
   - same-plate fraction of the 15 nearest neighbours: 0.093, against 0.079
     if plates were fully mixed within cell lines; plate entropy 2.91 against
     3.02 bits;
   - preservation of PC-space neighbourhoods depends on the size of the
     sample searched: 0.027 (1M cells), 0.116 (100k), 0.371 (10k), 0.480
     (5k). Placed cells score 0.003-0.015 below reference cells at each size.

The placed cells are an out-of-sample projection, not a joint UMAP of all
95.6M cells. Distances and densities in the layout are not quantitative.
