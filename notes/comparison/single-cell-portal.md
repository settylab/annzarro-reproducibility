### What it is

Single Cell Portal (SCP) is the Broad Institute's hosted repository and viewer for single-cell studies. Study owners upload cluster files, metadata, expression matrices or an AnnData file through a web wizard; SCP ingests them into its own database (MongoDB) and Google Cloud buckets, and visitors explore each study in a browser (scatter, violin, dot plot, heatmap, spatial side-by-side plots, precomputed DE tables). It is one central deployment, not software you run yourself. On 2026-10-03 the public API listed 1,050 public studies.

**Primary paper.** Tarhan L, Bistline J, Chang J, Galloway B, Hanna E, Weitz E (2023). Single Cell Portal: an interactive home for single-cell genomics data. *bioRxiv* preprint, posted 17 July 2023. DOI [10.1101/2023.07.13.548886](https://doi.org/10.1101/2023.07.13.548886). Crossref-verified (title, six authors, date 2023-07-17, no container title). These are all six authors.

### How to validate it yourself

1. Open [SCP383](https://singlecell.broadinstitute.org/single_cell/study/SCP383) without logging in, go to Explore. The plot loads; in Options, "Subsampling" shows 100000. Switch to "All Cells" and watch the URL gain `subsample=all` (S2, S4, shareable state).
2. Run `curl -s 'https://singlecell.broadinstitute.org/single_cell/api/v1/studies/SCP383/clusters/1M%20cell%20clusters?fields=coordinates' | python3 -c 'import sys,json;d=json.load(sys.stdin);print(d["numPoints"],len(d["data"]["x"]))'`; expect `1306127 100000`.
3. Same for SCP2805 with cluster `UMAP`; expect `3177310 3177310` (about 59 MB; S1, and the unsubsampled case).
4. Read the [subsampling doc](https://singlecell.zendesk.com/hc/en-us/articles/360060610032-Cluster-file-subsampling) and `cluster_group.rb#L67-L70` and `SubsampleSelector.jsx#L14-L31` at `1fd5f77`.
5. On SCP2805 Explore, open the Differential expression panel, click a gene: scatter and distribution update together (feature colouring, (a2): focus column N under the strict definition; precomputed DE). Confirm no "compute DE" button exists.
6. Hover any scatter: the Plotly mode bar shows a camera icon "Download plot as a png" (plot export).
7. Open [SCP2510](https://singlecell.broadinstitute.org/single_cell/study/SCP2510) Explore, pick a spatial group in Options: spatial X/Y plot beside the UMAP, no tissue image (spatial Y, underlay N).
8. Sign in with Google on any public study, use the lasso ("Create annotation"), name a selection and save: a new user annotation appears in the annotation menu (annotation editing).
9. Crossref: `curl -s https://api.crossref.org/works/10.1101/2023.07.13.548886` (preprint only) and `curl -s https://api.biorxiv.org/pubs/biorxiv/10.1101/2023.07.13.548886` ("no articles found for published version").
10. Focus and selection: follow "Focus, feature colouring and selection (checked in the running app)" above on SCP1671 (DE click on CD74 recolours scatter and violins; the "Filter plotted cells" facet greys cells in every scatter; a lasso stays in its own plot). Decides Column 3 (N) and the selection column (Y, or P if lasso linking is required).
