SCREENSHOTS: provenance manifest (all copied byte-for-byte from scsva/runs/<label>_<job>/; nothing was re-run)

Common to all runs:
  Launcher: sbatch --mem=16G run/run_job.sh <label> inputs/<dataset> <GENE> shots
    (copy: screenshots/provenance/run_job.sh). It starts scSVA via screenshots/provenance/launch.R
    (R 3.6.2 module + recipe/ env; two host shims only: bitmapType=cairo, shinyFiles volumes)
    and drives it with screenshots/provenance/drive.py: Playwright 1.25, headless Chromium 105, viewport 1600x1000.
  App state: scSVA defaults throughout. Grid Resolution 512 (the drive never moves the slider), Point Size 0.1,
    palette inferno, log10 colour scale, gene statistic Mean.
  The image the server sends: one PNG, 755x700 px (timings.json "plot1_img_natural").
  Per-run evidence: screenshots/provenance/<label>_<job>/{drive.log, timings.json, run.json}.
