### What it is

Vitessce is a browser-side visualization framework from the HIDIVE lab (Nils Gehlenborg, Harvard Medical School). A JSON view configuration (or one built in Python or R) says which views to show, which files feed them and how the views are coordinated; the views are React components that read AnnData zarr, OME-zarr/TIFF, SpatialData and other files directly from static hosts. It ships as a web app (vitessce.io), a React component, a Jupyter widget (`vitessce-python`) and an R htmlwidget.

**Primary paper.** Keller MS, Gold I, McCallum C, Manz T, Kharchenko PV, Gehlenborg N. (2025) Vitessce: integrative visualization of multimodal and spatially resolved single-cell data. *Nature Methods* 22(1):63-67 (online 27 Sep 2024). [doi:10.1038/s41592-024-02436-x](https://doi.org/10.1038/s41592-024-02436-x). Crossref-verified 2026-10-03 (title, journal, volume 22, issue 1, pages 63-67, six authors).

### How to validate it yourself

1. Crossref: `curl -s https://api.crossref.org/works/10.1038/s41592-024-02436-x | head -c 600` shows the title, Nature Methods, volume 22.
2. Open https://vitessce.io/#?dataset=habib-2017. Click a gene in the "Genes" list: the UMAP and the violin plot both switch to that gene (focus P).
3. In the same view, hover the top right of the cell-set sizes bar plot or violin plot and open the "..." menu: if "Save as PNG" and "Save as SVG" appear, plot export is P. Then confirm the UMAP panel offers no image download (its cloud menu lists data files only).
4. Still there, uncheck all but one cell set in "Cell Sets": the other cells turn grey but remain drawn (table filters P, S4 highlight only).
5. Click "Edit" in the toolbar above the views: the editor opens with a `data:,` URL holding the current gene selection and zoom (shareable view state Y).
6. Open https://vitessce.io/#?dataset=salcher-2022 and wait for the UMAP: 1,283,972 cells drawn as points. Confirm the count with `curl -s https://storage.googleapis.com/vitessce-demo-data/salcher-2022/salcher_2022_extended.h5ad.zarr/obsm/X_umap/.zarray | grep -A2 shape`. In DevTools Network, selecting a gene fetches a single `X/0.N` chunk (lazy per-gene reads).
7. Open https://vitessce.io/#?dataset=human-lymph-node-10x-visium: spots drawn over the H&E image (spatial Y, image underlay Y).
8. obsp/varp: in `$DEMO_ROOT/vitessce/src` run `grep -rIlE "obsp|varp|obsPairs" packages | grep -v fixture` (expect only `generate-config.test.js`), and read the DataType list at `packages/constants-internal/src/constants.ts` L41-62.
9. Scatterplot draws every point: read `packages/view-types/scatterplot/src/Scatterplot.js` L470-479 (`length: obsEmbedding.shape[1]`) and L292 (`ScatterplotLayer`).
10. Run `$DEMO_ROOT/vitessce/start.sh`, then open https://vitessce.io/#?url=http://127.0.0.1:8904/config.json (hash form; allow the browser's local-network-access prompt). The hosted app reads the shared bone marrow AnnData zarr (8,090 cells, with three obsp matrices) from your machine; nothing is uploaded. Repeat steps 2 to 4 on your own data; check that no obsp key (e.g. `connectivities`) is offered anywhere as a colour.
11. Focus and selection: follow the four rows of "Focus, feature colouring and selection (checked in the running app)" above (Mpo in the Gene List recolours both scatterplots; a UMAP lasso highlights in FA and filters the heatmap; hover, not click, links a single cell). Decides Column 3 (N) and the selection column (Y).
