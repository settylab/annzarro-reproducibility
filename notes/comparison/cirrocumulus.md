### What it is

Cirrocumulus is a web viewer for single-cell and spatial data. It was written at the Broad Institute (Klarman Cell Observatory; Bo Li's group) and Genentech has maintained it since 2022. A React/WebGL client talks to a Python (Flask) server. The server runs locally (`cirro launch`), as a multi-user deployment with MongoDB and Google/Okta login (`cirro serve`), or is left out altogether in a static-website build that reads prepared JSONL files over HTTP.

**Primary paper: there is no dedicated paper.** Cirrocumulus is described as the visualisation component of Cumulus. The Results describe it as "a serverless application that enables interactive data visualization and sharing ... Since Cirrocumulus only downloads to the browser those data that are necessary for visualization, it is scalable to millions of cells". The Methods have a section, "Cirrocumulus implementation", with the React/WebGL client, the Python server, JSON/Parquet slicing and an optional server-side "statistical summaries on an n-dimensional grid".
Li B, Gould J, Yang Y, Sarkizova S, Tabaka M, Ashenberg O, et al. (2020). Cumulus provides cloud-based data analysis for large-scale single-cell and single-nucleus RNA-seq. *Nature Methods* 17, 793-798. [doi:10.1038/s41592-020-0905-x](https://doi.org/10.1038/s41592-020-0905-x). Crossref-verified 2026-10-03; PMC7437817. I read the full text through NCBI BioC (`https://www.ncbi.nlm.nih.gov/research/bionlp/RESTful/pmcoa.cgi/BioC_json/PMC7437817/unicode`, search "Cirrocumulus").

**Disagreements with current marks**

None. Every mark is confirmed at cae75c9. Caveats for the caption or notes, not mark changes:
- lazy chunked Y holds for prepared data (zarr, parquet, JSONL). `cirro launch` on a plain h5ad loads the whole file into server memory.
- static site Y keeps viewing, filters, Copy Link and image export, but loses DE and annotation.
- Reported scale "1.3M cells" now has a source: docs/documentation.rst L40. The dataset itself is unnamed in the docs, so treat it as "1.3M cells (docs GIF)".
- The paper text should not say Cirrocumulus has "no paper" without qualification. It is described inside the Cumulus paper (Li et al. 2020, Methods "Cirrocumulus implementation"), which is the right citation.

### How to validate it yourself

1. Open https://cirrocumulus.readthedocs.io/en/latest/documentation.html and search for "1.3 million". The sentence and the GIF are under "Primary embedding" (S1).
2. Open the Cumulus paper (https://doi.org/10.1038/s41592-020-0905-x, or PMC7437817). Search for "Cirrocumulus": Results ("serverless application ... scalable to millions of cells") and the Methods section "Cirrocumulus implementation".
3. Open http://127.0.0.1:8901 (the coordinator's local `cirro launch` on the 8,090-cell bone-marrow h5ad). Check that all 8,090 cells are drawn. Pick a gene, lasso a group, and see the selection highlighted in the gallery plots and a "(selection)" panel under Distributions.
4. In the same instance, use the toolbar camera icon ("Save Image") to get PNG and SVG (plot export Y). Then use More menu > Copy Link, paste the link into a new tab, and check that the view comes back (shareable state Y).
5. Run differential expression on the lasso selection from the side bar (on-the-fly DE Y). Rename a category in the categorical legend (annotation editing Y).
6. Look at [docs/installation.rst#L94-L141](https://github.com/lilab-bcb/cirrocumulus/blob/cae75c9a2dd164dda07eaae5693e28ea0408f8b2/docs/installation.rst#L94-L141) for the static-site recipe, and [src/actions/index.js#L195-L196](https://github.com/lilab-bcb/cirrocumulus/blob/cae75c9a2dd164dda07eaae5693e28ea0408f8b2/src/actions/index.js#L195-L196) for the empty capability set that turns off DE and annotation there.
7. Look at [cirrocumulus/launch.py#L42](https://github.com/lilab-bcb/cirrocumulus/blob/cae75c9a2dd164dda07eaae5693e28ea0408f8b2/cirrocumulus/launch.py#L42) and [cirrocumulus/anndata_dataset.py#L114-L128](https://github.com/lilab-bcb/cirrocumulus/blob/cae75c9a2dd164dda07eaae5693e28ea0408f8b2/cirrocumulus/anndata_dataset.py#L114-L128). `cirro launch` reads the h5ad unbacked (S3 caveat).
