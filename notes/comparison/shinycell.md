### What it is

ShinyCell is an R package from the Rackham and Ouyang groups (Duke-NUS Medical School, Singapore) that turns one Seurat, SingleCellExperiment, h5ad or loom object into a small, fixed-layout Shiny app. The build step writes the expression matrix to an HDF5 file, metadata and embeddings to RDS files, and generates `server.R` and `ui.R` with fixed tabs (cell info vs gene expression on an embedding, coexpression, violin/box, proportion, bubble/heatmap). ShinyCell2 (Ouyang lab, same institute) is the successor: it adds spatial, scATAC-seq (ArchR, Signac) and multi-assay tabs, side-by-side and zoomable plots, and an image underlay for spatial data. Every plot is drawn server-side by R with ggplot2.

**Primary paper.** Ouyang JF, Kamaraj US, Cao EY, Rackham OJL. (2021) ShinyCell: simple and sharable visualization of single-cell gene expression data. *Bioinformatics* 37(19):3374-3376. [doi:10.1093/bioinformatics/btab209](https://doi.org/10.1093/bioinformatics/btab209). Crossref-verified 2026-10-03 (title, journal, volume 37, issue 19, pages 3374-3376, four authors). Preprint: [doi:10.1101/2020.10.25.354100](https://doi.org/10.1101/2020.10.25.354100) (Crossref-verified).

**ShinyCell2 paper.** Chen BJ, Lim YY, Yang X, Wang L, Rackham OJL, Ouyang JF. (2025) ShinyCell2: An extended library for simple and sharable visualisation of spatial, peak-based and multi-omic single-cell data. *bioRxiv* preprint, posted 23 Apr 2025. [doi:10.1101/2025.04.22.650045](https://doi.org/10.1101/2025.04.22.650045). Crossref-verified 2026-10-03. Still a preprint: Crossref has no `is-preprint-of` relation and a title search for "ShinyCell2" returns only this record. Cite it as a preprint.

**Related, not by the authors.** Moore D, Granger B, Berto S. (2025) ShinyCellPlus: an improved ShinyCell application for the interactive visualization of single cell data. *F1000Research* 14:338. [doi:10.12688/f1000research.161076.1](https://doi.org/10.12688/f1000research.161076.1) (Crossref-verified). Not audited here.

**The "~30k cells per 8 GB RAM" scale label.** The source exists, but the figure misreads it. Both READMEs say, in the FAQ, that a large amount of memory is needed when *building* the app because the whole object is loaded, and "From experience, a typical laptop with 8GB RAM can handle datasets around 30k cells while 16GB RAM machines can handle around 60k-70k cells" (SC [`README.md#L199-L204`](https://github.com/SGDDNB/ShinyCell/blob/5c61db78cdd624636e161406d5d42aeb2c0f1205/README.md#L199-L204); SC2 [`README.md#L203-L210`](https://github.com/the-ouyang-lab/ShinyCell2/blob/33bfc8ba232f0c829b6b23181cb83089d58e7879/README.md#L203-L210), which adds "for scRNA-seq data" and "if you are able to perform analysis ... on the machine, the machine should be able to build the app"). The same FAQ says the running app "consumes very little memory". So it is a build-machine rule of thumb, not the viewer's scale. As a scale cell it undersells ShinyCell and is the wrong kind of number next to the other rows. Proposed text: "162k cells (ShinyCell2 tutorial)".

### How to validate it yourself

1. Open [shinycell1.ddnetbio.com](http://shinycell1.ddnetbio.com) (allow ~5 s). Tab "CellInfo vs GeneExpr": change the gene on the right; confirm the left plot and other tabs do not change (focus N), and that "Download PDF"/"Download PNG" save the plot (export Y).
2. Same tab, click "Toggle to subset cells", pick a field, untick a few groups: the unticked cells turn grey on the embedding (S4 yes, per plot only, so table filters N).
3. Look for any share, bookmark or "copy link" control, and for an editable label field: none (shareable view N, annotation N).
4. Open [shinycell.ouyanglab.com](https://shinycell.ouyanglab.com/), tab "Side-by-side Spatial": spots drawn over the tissue image (ShinyCell2 spatial and image underlay). Note shinycell2.ddnetbio.com is ShinyCell, not ShinyCell2.
5. Read the FAQ at [ShinyCell README L192-L204](https://github.com/SGDDNB/ShinyCell/blob/5c61db78cdd624636e161406d5d42aeb2c0f1205/README.md#L192-L204): the 30k/8 GB number is about *building*, and the running app is called low-memory.
6. Open [`R/makeShinyFiles.R#L314-L317`](https://github.com/SGDDNB/ShinyCell/blob/5c61db78cdd624636e161406d5d42aeb2c0f1205/R/makeShinyFiles.R#L314-L317) (per-gene chunks) and [`R/writer.R#L166-L170`](https://github.com/SGDDNB/ShinyCell/blob/5c61db78cdd624636e161406d5d42aeb2c0f1205/R/writer.R#L166-L170) (one row read) to judge lazy reads P vs Y.
7. Open [`R/writer.R#L104-L128`](https://github.com/SGDDNB/ShinyCell/blob/5c61db78cdd624636e161406d5d42aeb2c0f1205/R/writer.R#L104-L128): `sample(nrow(ggData))` reorders, `geom_point` draws all rows (S2 all cells).
8. Open the [CITE-seq tutorial](https://htmlpreview.github.io/?https://github.com/the-ouyang-lab/ShinyCell2-tutorial/master/docs/tutCiteseq.html), first paragraph: 161,764 cells, loaded with `readRDS("multimodal_pbmc.rds")` and passed whole to `makeShinyFiles` (S1).
9. If you have the Bioinformatics paper (doi:10.1093/bioinformatics/btab209) to hand, scan it for a larger dataset than 162k; I could not retrieve the PDF.
10. Run `$DEMO_ROOT/shinycell/start.sh`, then open the ShinyCell 2.1.0 app built from the shared bone marrow data at http://127.0.0.1:8907. The UI answered 200 on 2026-10-03; plot rendering was not checked and repeat steps 1 to 3 on your own data; time a gene change to see the per-gene HDF5 read.
11. Focus vs selection: run the app (`$DEMO_ROOT/shinycell/start.sh`) and repeat the four rows of "Focus, feature colouring and selection" above (gene in one plot only, stored row 4236 as cell information, per-tab subset, click does nothing).
