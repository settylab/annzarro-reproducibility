### What it is

SCope is a web viewer for single-cell datasets stored as `.loom` (HDF5) files, built by the Aerts lab (VIB-KU Leuven). A Python server (loompy/h5py, gRPC) reads the loom files; a React client draws the embedding with PIXI.js (WebGL, canvas fallback). Its specialities are SCENIC output (regulons, regulon AUC, motif logos), up to three genes shown at once as RGB channels, a Compare page that splits cells by annotation across up to four displays, and ORCID-signed collaborative cluster annotation. It is the public portal for the Fly Cell Atlas.

**Primary paper** (Crossref-verified; SCope is introduced in its Fig. 7 and the section "SCope: Cloud-Based Exploration of Single-Cell Atlases"): Davie K, Janssens J, Koldere D, De Waegeneer M, Pech U, Kreft Ł, et al. (24 authors). A Single-Cell Transcriptome Atlas of the Aging Drosophila Brain. *Cell* **174**(4), 982-998.e20 (2018). [doi:10.1016/j.cell.2018.05.057](https://doi.org/10.1016/j.cell.2018.05.057). Open access: [PMC6086935](https://europepmc.org/article/PMC/PMC6086935).

### Cells-drawn measurement (Fig. 1c cells strip): measured

Measured by the ceiling-benchmarker agent on 2026-10-07/08; record in `benchmark/tool_ceiling/measured/scope/` (README, run logs and the build history). SCope 1.8.2 at 9ae5207, the build the public site serves, was built from its repository with its code unchanged and conda-forge packages only (nine build-environment changes, all listed in the record; amd64 emulation), and run with the same task and rules as every other web tool. It ran with four run-time settings, also listed there: the database URL from SCope's own `.env`, a config binding its servers to 0.0.0.0, its frontend served by a static file server (Python's http.server, where the published docker-compose puts Apache), and the database migration step skipped (its versions folder is empty). Every cell was drawn at 1 million (client 4.03 GiB); at 2 million the Chromium renderer crashed in both attempts while the embedding was drawn, at 4.7 GiB of client memory, far below the 16 GiB budget, with 49.8 MB of JS heap at the last sample. Fig. 1c shows a failure triangle at 1M; Supp. Note 1 states the result. The first two build attempts (2026-10-06: the unmodified Dockerfile on Debian 13, then Debian 11 pinned) failed; their logs are kept in the same record.

### How to validate it yourself

1. Open <https://scope.aertslab.org>, decline cookies. The Welcome page lists public sessions up to 2025. Confirm the served build is 1.8.2 by `curl -sL https://scope.aertslab.org | grep scope_js` (expect `SCope-1.8.2.9ae5207.js`).
2. Paper: open [doi:10.1016/j.cell.2018.05.057](https://doi.org/10.1016/j.cell.2018.05.057), find "SCope: Cloud-Based Exploration of Single-Cell Atlases" and the "57K and 157K datasets" sentence.
3. S1/S2: go to <https://scope.aertslab.org/#/FlyCellAtlas/*/welcome>, expand `10x` (click the arrow icon, not the label), `All`, `Relaxed`, click `r_fca_biohub_all_wo_blood_10x`. In DevTools console run: `(()=>{const c=document.querySelector('canvas');let f=c[Object.keys(c).find(k=>k.startsWith('__react'))];while(f&&!(f.stateNode&&f.stateNode.state&&f.stateNode.state.coord))f=f.return;return f.stateNode.state.coord.x.length})()` → 567950.
4. Lazy reads: type `elav` in the red search box, pick the gene; colouring appears in seconds. Then read `SC opt/scopeserver/dataserver/utils/loom.py#L776-L777` (one-row slice).
5. Shareable state: click the link icon in the header, get a bit.ly permalink, open it in a private window; the same loom, page and gene load. Source `AppHeader.jsx#L422-L441`.
6. Filters/subset: click `Compare`, drag an annotation value (e.g. a tissue) onto a display; only those cells are drawn. Source `GServer.py#L333-L343`.
7. Annotation editing: `loom.py#L110-L114`, `#L118`, `#L149`, `#L371` (writes to loom `MetaData`); the UI needs ORCID login (button in header), so check code rather than editing the public data.
8. Plot export: in the viewer toolbar there are only lasso and zoom-reset buttons (`ViewerToolbar.jsx`); run `grep -rn -i 'toDataURL\|toBlob\|saveAs' src` in the clone: nothing.
9. Desktop app: open <https://github.com/aertslab/SCope/releases>; newest asset is the 2019 v1.3.5 CI prerelease, macOS/Linux only.
10. Mirror: `curl -sI http://scope-mirror.aertslab.org/` returns 503. No local fallback is installed. If the public site is down, see the repository README for a Docker setup.
11. Focus and selection: follow "Focus, feature colouring and selection (checked in the running app)" above on `Wouters_Human_Melanoma/10_Baselines_filteredRegulons` (picking `MITF_motif_regulon` recolours all three Regulon-page viewers).
